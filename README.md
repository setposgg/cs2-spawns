# CS2 spawns

100 competitive spawn positions for seven Counter-Strike 2 maps, with diagrams, console commands, JSON and CSV.

![Mirage numbered T and CT spawns](maps/mirage.svg)

## Use in game

Load a map on a local practice server and run `sv_cheats 1` in the console.
Paste a command from the tables below to TP to that spawn.
The optional `setang` part sets the direction you face when you spawn.
Short ticks on the diagrams show that direction; linked numbers open available lineups.

## Data

[spawns.json](spawns.json) contains `{ "schemaVersion": 1, "spawns": [...] }`.
`csv/<map>.csv` has the same records (nulls are empty); `maps/<map>.svg` has the diagrams.
[angle-evidence.json](angle-evidence.json) records the measurements and demo checks.

| Field | Meaning |
| --- | --- |
| `map`, `side`, `label` | Map slug, `t` / `ct`, and spawn number. |
| `x`, `y`, `z` | Position in world units at the player's feet. |
| `zStatus` | `observed-feet`, `published-lineup-feet`, or `entity-origin-unsettled`. |
| `pitch`, `yaw` | Verified facing in degrees; otherwise `null`. |
| `angleStatus` | `runtime-verified` or `unverified`. |
| `setpos` | Position command, preserving the numeric fields' precision. |
| `setposSetang` | Position and facing command; `null` without verified angles. |
| `url` | Published spawn page, or `null` if none exists yet. |

Positions come from player feet observed in 5v5 demos and published lineup commands; angles are matched to map entities and the earliest replicated eye angles at round resets in pro demos. Measurements, source hashes and outliers are in [angle-evidence.json](angle-evidence.json).

## Numbering

Each side starts at 1 and follows [setpos.gg](https://setpos.gg).
Face the team's general exit: count left to right across a wide spawn, or front to back through a deep one.
Ties go front first across, left first back. All diagrams are north-up.
